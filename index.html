검색 결과에 관한 안내

  • 검색 결과, 조회수, 제목, 썸네일은 YouTube Data API에서 가져옵니다.
  • API는 Shorts 여부를 별도 필드로 제공하지 않습니다. 검색어에 쇼츠·shorts를 넣어 후보를 찾지만 쇼츠만 100% 골라내지는 못합니다.
  • API 키는 개인용으로 사용하고 Google Cloud에서 YouTube Data API v3와 웹사이트 리퍼러 제한을 설정하는 것을 권장합니다.
